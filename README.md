# Employee Management System 🚀

A full-stack MERN application to manage employee records.

## Features
- Add Employees
- View Employees
- Delete Employees
- MongoDB Database Integration
- REST API using Express.js
- React Frontend

## Tech Stack

### Frontend
- React.js
- Vite
- Axios

### Backend
- Node.js
- Express.js
- MongoDB Atlas
- Mongoose

## Installation

### Backend

```bash
cd backend
npm install
npm run dev
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

## API Routes

| Method | Route | Description |
|--------|-------|-------------|
| GET | /api/employees | Get all employees |
| POST | /api/employees | Add employee |
| DELETE | /api/employees/:id | Delete employee |
